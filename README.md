# Сумрачный вал (Voxel Tower)

Оборона из микро-вокселей на Godot 4.7 и C#. Стены, башни и ступени строятся из материала, воксель — 6,25 см:
воин ростом около 30 вокселей, полметра стены — 8. Строительство мгновенное, если хватает золота и земли.

## Как открыть

- **Редактор:** двойной щелчок по `open-editor.command`. В редакторе F5 или ▶ запускает игру.
- **Сразу игра:** `run-game.command`.

Скрипты нужны из-за .NET. Godot ищет его в `/usr/local/share/dotnet`, а здесь .NET 10 стоит через Homebrew, и скрипт
подсказывает Godot путь. Если поставить официальный .NET SDK с dotnet.microsoft.com (понадобится пароль), Godot можно
будет открывать и из Dock.

## Управление

| Действие | Как |
| --- | --- |
| Строить | ЛКМ; стену и ступени — протяжкой |
| Инструменты | 1 стена, 2 башня, 3 ступени, 5 кисть, 6 копать, 7 насыпать, 8 разобрать, B снять чертёж |
| Повернуть чертёж | R |
| Убрать инструмент | Esc или щелчок ПКМ |
| Сдвинуть карту | протяжка ПКМ, WASD или стрелки |
| Повернуть вид | СКМ, Alt+ЛКМ, Q/E |
| Масштаб | колесо |
| Вернуть вид | H |

Пока работает только стройка: орду, стражу и разрушения переношу следующими шагами.

## Устройство

- `src/Core` — мир на чистом C#, без Godot: воксели в чанках 32³ (однородные чанки не занимают памяти), генерация
  карты, жадный мешер с затенением углов, кисти (четыре профиля стен, башня, ступени, шар, насыпь), копание, разбор,
  чертежи, луч по вокселям. Работает и проверяется без движка.
- `src/Game` — слой Godot: чанки на экране, камера-диорама, свет и небо, инструменты с призраком постройки, панель.
- `shaders` — воксель (разброс цвета, фаска, свечение жара), призрак постройки, сумеречное небо.
- `tools/CoreBench` — проверка ядра из командной строки.

Карта и постройки совпадают с браузерным прототипом до вокселя: 232 642 треугольника.

## Проверки

```bash
cd tools/CoreBench && dotnet run -c Release
```

Ядро сверяется с прототипом и меряется по скорости.

```bash
./run-game.command -- --selftest
```

Godot прогоняет все инструменты синтетическими щелчками и протяжками.

Ещё флаги после `--`: `--demo` строит несколько вещей для показа, `--shot=файл.png` делает скриншот и выходит,
`--calm` выключает искры и мерцание.

### Стража: приказы и свой ИИ

Приказ задаёт намерение: пост, участок стены, цель, режим («держать пост», «защищать участок», «свободная охота»).
Как его выполнить, воин решает сам:

- стреляет в самых опасных: тех, кто рубит стену или лезет по лестнице;
- сбрасывает вражеские лестницы рядом;
- отходит, если истекает кровью;
- помогает соседу, если тот в пределах поводка;
- бежит к цитадели, когда её штурмуют, и потом возвращается на пост.
