# Сумрачный вал (Voxel Tower)

Оборона из микро-вокселей на Godot 4.7 и C#. Воксель — 6,25 см: воин ростом около 30 вокселей, полметра стены — 8.

Готовых построек нет. Стены, башни и лестницы рисуются кистями из материала, а всё, что стоит повторять,
снимается в чертёж и ставится снова одним щелчком. Цена считается по вокселям: камень 10 золота за кубометр
(4096 вокселей), брёвна 5, землю добывают лопатой. Строительство мгновенное.

## Как открыть

- **Редактор:** двойной щелчок по `open-editor.command`. В редакторе F5 или ▶ запускает игру.
- **Сразу игра:** `run-game.command`.

Скрипты нужны из-за .NET. Godot ищет его в `/usr/local/share/dotnet`, а здесь .NET 10 стоит через Homebrew, и скрипт
подсказывает Godot путь. Если поставить официальный .NET SDK с dotnet.microsoft.com (понадобится пароль), Godot можно
будет открывать и из Dock.

## Кисти

| Клавиша | Кисть | Что делает |
| --- | --- | --- |
| 1 | Кисть | Мазок от руки. Столб — стена до заданной высоты, шар — налипает на поверхность, перекраска — меняет материал своей кладки |
| 2 | Линия | Прямая полоса заданной толщины и высоты: стены, галереи |
| 3 | Прямоугольник | Сплошной (помост, основание) или только стенки (квадратная башня, двор) |
| 4 | Круг | Сплошной (бастион) или кольцо (круглая башня) |
| 5 | Выдавить | Ровная грань своей кладки нарастает на шаг: поднять стену на ряд, надстроить деревянный верх |
| 6 | Ластик | Стирает свою кладку, возвращает половину цены камня и брёвен и всю землю |
| 7 | Лопата | Копает грунт и дёрн, скалу не берёт; земля идёт на насыпи |
| B | Снять чертёж | Рамкой вокруг своей постройки; копии ставятся из свитков справа, R поворачивает |

Пока тянешь линию, прямоугольник, круг или стену кистью, конец идёт по плоскости, где начал, поэтому уже
нарисованное не цепляет курсор. Кисти смотрят сквозь кроны деревьев на землю.

## Управление

| Действие | Как |
| --- | --- |
| Материал | Z камень, X брёвна, C земля |
| Толщина / размер | `[` и `]` |
| Высота (шаг выдавливания, глубина лопаты) | `−` и `=` |
| Форма кисти, сплошной или стенки | F |
| Верх ровный или по рельефу | G |
| Стереть кистью | Shift + ЛКМ |
| Убрать кисть | Esc или щелчок ПКМ |
| Сдвинуть карту | протяжка ПКМ, WASD или стрелки, щелчок по карте долины |
| Повернуть вид | СКМ, Alt+ЛКМ, Q/E |
| Масштаб | колесо |
| Вернуть вид | H |

Подсказки по всем кнопкам — при наведении, полный список управления — на медальоне «?» справа вверху.

Пока работает только стройка: орду, стражу и разрушения переношу следующими шагами.

## Устройство

- `src/Core` — мир на чистом C#, без Godot: воксели в чанках 32³ (однородные чанки не занимают памяти), генерация
  карты, жадный мешер с затенением углов, кисти (`Shapes`: линия, прямоугольник, круг, шар, выдавливание,
  перекраска), копание, разбор, чертежи, луч по вокселям. Работает и проверяется без движка.
- `src/Game` — слой Godot: чанки на экране, камера-диорама, свет и небо, кисти с призраком постройки.
- `src/Game/Ui` — интерфейс поверх игры: кованые плиты, гравированные иконки, миникарта. Всё рисуется кодом, файлов
  с картинками нет.
- `shaders` — воксель (разброс цвета, фаска, свечение жара), призрак постройки, сумеречное небо.
- `tools/CoreBench` — проверка ядра из командной строки.
- `prototypes` — четыре браузерных прототипа, с которых всё началось.

## Проверки

```bash
cd tools/CoreBench && dotnet run -c Release
```

Ядро сверяется с прототипом (232 642 треугольника на карте со старой крепостью) и проверяет все кисти.

```bash
./run-game.command -- --selftest
```

Godot прогоняет все кисти синтетическими щелчками и протяжками.

Ещё флаги после `--`: `--demo` рисует небольшую крепость кистями, `--pose=line` показывает линию в процессе,
`--shot=файл.png` делает скриншот и выходит, `--calm` выключает искры и мерцание.

### Стража: приказы и свой ИИ

Приказ задаёт намерение: пост, участок стены, цель, режим («держать пост», «защищать участок», «свободная охота»).
Как его выполнить, воин решает сам:

- стреляет в самых опасных: тех, кто рубит стену или лезет по лестнице;
- сбрасывает вражеские лестницы рядом;
- отходит, если истекает кровью;
- помогает соседу, если тот в пределах поводка;
- бежит к цитадели, когда её штурмуют, и потом возвращается на пост.
