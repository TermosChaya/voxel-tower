# Набеги без волн

Автор (25.10.2026): «механика волн пропадет вместе с глобальной картой — отвязываем от нее механики». На глобальной
карте враг ходит по клеткам, набег начинается, когда его войско входит в клетку с замком; фиксированного времени
набега нет. Пока карты нет, осада из двенадцати ночей остаётся одним из способов приводить набеги.

## Как устроено теперь (`src/Core/Sim.Raids.cs`)

- **Сутки — сами по себе** (`DayClock`, `Sim.Clock`): 10 минут дня (последняя — закат), ночь, полминуты рассвета.
  Ночь держится, пока в долине набег, пришедший ночью, и кончается вместе с ним; ночь без набега — 2,5 минуты. Солнце
  можно остановить в полдень (песочница по зову): сутки всё равно считаются, каждые 10 минут. Номер дня — `Clock.Day`.
- **Набег в долине — сам по себе** (`Raids`, `Sim.Raids`): ватаги входят одна за другой, набег кончается, когда
  входить некому и в долине никого нет. Он не знает, кто его привёл, и не знает своей силы: ему говорят
  (`Raids.Threat`, `Raids.Intel`). Счётчики: `Count` (пришло), `Repelled` (отбито), `AtNight`.
- **Кто приводит набеги** (`IRaidSource`, `Sim.Source`):
  - `SiegeScenario` («siege») — осада как была: набег на каждом закате, двенадцать, угроза — номер ночи; «На штурм»
    зовёт раньше, и ночь наступает сразу; посол может отсрочить на 3 минуты.
  - `OnCallRaids` («call») — песочница: только по зову, солнце стоит в полдень.
  - `MapRaids` («map») — заготовка для карты: никакого расписания, ночи проходят сами, набег — только через
    `Sim.Raid`; угроза растёт по дням. Игроку его не позвать. Включается флагом `--raids=map`.
- **Вход для карты:** `Sim.Raid(состав, сторона, разведка)` — эти виды входят с этой стороны шестиугольника (0 — от
  северного угла по востоку, `Sim.WestEdge` = 4 — западная), сразу, днём или ночью; если набег уже идёт, они к нему
  присоединяются. Ватага помнит сторону (`Warband.Edge`) и при бегстве уходит туда же.
- **Старое лицо** `Sim.Waves` (класс `Waves`) оставлено поверх этого: экран, тесты и постановки читают и ставят
  `Number`, `Active`, `Countdown`, `OnCall` как раньше. Новому коду лучше читать `Raids`, `Clock`, `Source`.

## Что было привязано к волне и к чему теперь

| Было | Стало |
| --- | --- |
| Состав ватаг по номеру волны (`Roster(n)`) | По **угрозе** (`Sim.Threat`): что говорит источник (осада — номер ночи; карта — день) плюс поселение (четверть за каждое звание, `WealthShare`). Виды приходят по целой части угрозы, рядовые — по всей. Угроза n даёт ровно прежнюю волну n |
| Брёвна и земля, принесённые волной | По угрозе набега |
| Сапёры с порохом с 5-й волны | С угрозы 5 |
| Знания за волну: 3 + номер | **За дела:** отбитый набег — 2 + его угроза; павшие вожаки, тролли, колдуны, великаны, машины — доли знания (копятся, платятся с наградой); занятое место (рудник, место силы) — 1–2 сразу, один раз; построенное здание города или его второй этаж — 1 сразу |
| Золото за волну: 30 + 10 · номер | 30 + 10 · угроза набега |
| Прирост в зданиях — за 10 минут, непрерывно | **По дням:** на каждом рассвете запас растёт на прирост здания (неделя «Героев» → игровой день), до двойного |
| Дары рассвета после волны, кроме двенадцатой | После любого отбитого набега, кроме последнего в осаде; рыцарь и купеческий кошель — по угрозе |
| Поручение «Выстойте ночь n из 12» | Только где источник приводит конечное число набегов; иначе «Отбейте следующий набег» |
| Финал — после 12-й волны | Условие источника: осада кончается, когда отбит её последний набег |
| Автосохранение «волна отбита» | После любого отбитого набега |
| Погода с первой волны, медведь с третьей | Со второго дня (или первого отбитого набега), медведь с третьего дня (или двух отбитых) |
| Посол: только между волнами, отсрочка | Между набегами; отсрочка — только если источник ведёт время |
| Постепенное раскрытие: «первая ночь» | Первый набег или второй день |
| День и ночь — из отсчёта волны | Свои сутки (`DayClock`) |
| Часы: «Волна N из 12 · до орды» | Пишут источник: осада — как было; по зову — «по зову»; карта — «День N · нет вестей», кнопка «Орда не видна» |
| Вкладка «Орда» | Строка угрозы: из чего она и сколько ожидается |

## Как карта будет приводить набеги

Карта заведёт свой источник (или будет звать `Sim.Raid` из своего хода): войско врага входит в клетку долины →
`Sim.Raid(его состав, сторона, по которой оно вошло, сколько оно разведало)`. Угрозу задаёт само войско — его
состав и есть сила. Сутки на карте и в долине — одни. Что раньше давала волна, теперь даёт дело или день, поэтому
ничего из экономики, знаний и найма менять не придётся.

## Предложения на суд автора

- Доля поселения в угрозе — четверть ночи за звание (до +1,25 у «Города»). Можно убрать (`Sim.WealthShare = 0`)
  или сделать сильнее.
- Знаний за первую ночь теперь 3, а не 4 (2 + угроза 1); к концу осады — больше прежнего за счёт павших вожаков,
  колдунов, троллей и великана. Казарма (3 знания) по-прежнему ставится после первой ночи.
- Рост запаса в зданиях раз в день, ступенькой, как неделя в «Героях»; прежде шёл непрерывно.
- Ночь без набега — 2,5 минуты. В осаде таких ночей нет; на карте они будут.
